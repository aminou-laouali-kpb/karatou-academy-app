La fonctionnalité "Modules" délivre des "Cours" : on appelle ça des Cours.
Remplacer dans toute l'UI (composants, i18n, libellés, boutons, titres de sections) :


Nav "Modules" → "Cours"
Section "Nos Modules" → "Nos Cours"
Bouton "Voir les modules" → "Voir les cours"
Pricing : "Par module" → "Par cours" · "Tous les modules inclus" → "Tous les cours inclus"
Footer : lien "Modules" → "Cours"
Tout autre texte visible contenant "module(s)" → "cours" (singulier ET pluriel : "cours" reste "cours")


Ne touche PAS aux noms de variables/routes/fichiers de code si ça casse le build (ex. ancrage #modules peut rester en interne). C'est le texte VISIBLE par l'utilisateur qui doit dire "Cours".
