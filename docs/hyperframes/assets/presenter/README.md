# Photo du présentateur

Déposer ici le fichier attendu par la carte d'ouverture :

    aminou-laouali-abdou.jpg

Contraintes (détail complet en section 4 de `../../CONTEXTE-VIDEO.md`) :

- **Carré**, 1:1. Le cadre affiché fait 360 × 360 px sur le canvas 1920 × 1080.
- **1080 × 1080 px minimum** (3× la taille d'affichage, pour rester net après encodage).
- JPEG qualité ≥ 90, ou PNG. Pas de fichier progressif.
- Cadrage buste ou portrait serré, regard vers l'objectif, sujet centré horizontalement.
- Fond uni ou nettement détaché du sujet : la photo est posée sur un fond navy
  (`--gradient-dark`), un fond photo sombre ferait disparaître les contours.
- Aucune incrustation de texte, de logo ou de filigrane dans l'image elle-même.

Si la photo fournie n'est pas carrée, elle est recadrée au centre horizontalement et selon
`object-position` verticalement — la valeur exacte est fixée à la livraison de la photo, une
fois le cadrage réel connu.

Ce dossier est le dossier source. Dans le projet HyperFrames, le fichier est référencé
sous `assets/presenter/aminou-laouali-abdou.jpg`.
